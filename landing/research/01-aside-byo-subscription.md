## 0. 요약

1. **Aside는 "쓰던 구독 연결"을 주인공으로 쓰지 않는다.** 이 메시지는 프라이버시 섹션 카드 4장 중 마지막 1장, 그리고 가격표 Free 플랜의 항목 1줄에만 나온다. 주인공은 "실제로 일을 끝내는 에이전트"다. PRD 9장("무료는 USP가 아니라 진입 장벽 제거 수단")과 같은 판단이라, Experii 섹션 6도 **가볍고 짧게, CTA 직전에** 두는 쪽이 맞다.
2. **랜딩에는 "다운로드 → 구독 연결 → 사용" 단계 설명이 없다.** 그 대신 히어로에 코드로 그린 제품 시연을 넣었다. 커서가 움직이고, 요청 문장이 한 글자씩 입력되고, 작업 단계가 한 줄씩 나타나는 장면 하나로 "쓰면 이렇게 된다"를 보여 준다. 구독 연결 절차는 도움말 문서(Settings > Models > Providers > Connect > OAuth 팝업)에만 있다.
3. **히어로 시연은 영상이 아니라 HTML·코드 애니메이션이다.** 일시정지·재개·다시 보기 버튼이 붙어 있다. Experii가 "GPT와 공부하는 Experii 화면"을 보여 줄 때 거의 그대로 가져올 수 있는 구조다(4.2절에 스토리보드).
4. **신뢰는 구체적인 작은 UI 조각으로 만든다.** 권한 드롭다운, 토글, 접속 기록 표, 로컬/클라우드 선택 메뉴를 실제 화면처럼 잘라 카드에 넣고, 굵은 첫 문장과 회색 설명을 붙인다. Experii 섹션 6의 "3단계 아이콘 행"을 "3단계 미니 화면 카드"로 바꿀 근거가 된다.
5. **피할 것도 분명하다.** "가장 똑똑한", "SOTA", "#1", 경쟁사를 이겼다는 벤치마크, "지금의 AI 브라우저는 고장 났다" 같은 카테고리 비난은 모두 PRD 7장 금지 표현에 걸린다.
6. **H4(구독 연동 가능성)는 여전히 단정할 수 없다.** 2026-10-26에 읽은 Anthropic 공식 문서는 제3자 앱이 Claude.ai 로그인을 제공하거나 Free·Pro·Max 구독 자격으로 요청을 대신 보내는 것을 허용하지 않는다고 적고 있다. OpenAI의 "Sign in with ChatGPT" 구독 사용 권한은 2차 자료 기준으로 선정 파트너 한정 시범이다. 그리고 이 권한은 사용자의 기존 ChatGPT 대화를 앱에 넘기지 않는다고 한다. 랜딩 문구는 TSD 6.3대로 "준비하고 있어요" 같은 예정형을 유지해야 한다.

### 1.3 히어로: 메시지와 비주얼

- **헤드라인**: "The most intelligent AI assistant, but it's a browser." 데스크톱은 가운데 정렬 두 줄, 모바일은 왼쪽 정렬 세 줄이다. 서브카피는 없다. 헤드라인 바로 아래에 다운로드 버튼 하나만 둔다. `[확인]`
- **배지**: 헤드라인 위 알약 모양 "Backed by Y Combinator" 링크. 히어로에서 유일한 사회적 증거다. `[확인]`
- **CTA**: 검은 분할 버튼이다. 왼쪽은 접속한 OS에 맞춘 다운로드(캡처 환경에서는 Windows), 오른쪽 화살표는 다른 OS 선택이다. 같은 버튼이 내비게이션과 최종 CTA에 반복된다. `[확인]`
- **비주얼**: 구름 하늘 배경 위에 브라우저 창 하나를 그대로 그렸다. 왼쪽 세로 탭 사이드바(즐겨찾기, 채팅, 탭)와 오른쪽 본문이 보인다. 이 창 안에서 시연이 재생된다(1.6절 ①). 캡처 시점에 따라 장면이 다르다. 데스크톱 캡처는 작업 채팅 화면, 모바일 캡처는 "Recent tasks" 카드가 있는 새 탭 화면과 오른쪽 아래 다시 보기 버튼을 담고 있다. `[확인]`
- **읽히는 순서**: 배지(누가 믿어 주나) → 헤드라인(무엇인가) → 버튼(어떻게 시작하나) → 시연(정말 되나). 설명 문단 없이 시연이 설명을 대신한다.

### 1.4 사용자 흐름을 어떻게 설명하나 (다운로드 → 구독 연결 → 사용)

| 단계 | 랜딩에서 | 도움말 문서에서 |
|---|---|---|
| 다운로드 | 히어로·내비·최종 CTA의 OS 맞춤 버튼. 단계 안내는 없다 | "시작 전" 항목에 다운로드 링크와 OS 요구 사항(macOS 15 이상)이 있다 |
| 가입·초기 설정 | 언급 없음 | 5단계: Aside 열기 → 로그인 또는 계정 만들기 → 브라우저 데이터 가져오기 → 비밀번호 관리자 설정 → 작업 시작. 소요 시간 안내나 스크린샷은 없다 |
| 구독 연결 | 프라이버시 섹션 카드 1장, 문장 하나. ChatGPT·Claude 구독이나 자기 API 키를 쓸 수 있다는 내용 | 시작 5단계에 들어 있지 않다. 별도 페이지에 있다: Settings > Models > Providers > Connect → Subscription에서 ChatGPT 또는 Claude 선택 → OAuth 팝업에서 로그인. ChatGPT Plus·Pro, Claude Pro·Max를 지원한다고 적었고, 구독 사용량 표시도 있다고 한다 |
| 사용 | **히어로 시연 전체가 이 단계다.** 사용 사례 카드 3장, Memory 목업도 "요청 한 줄 → 결과 화면" 형식이다 | 작업 페이지 별도 |

**정리**: Aside 랜딩은 절차가 아니라 결과를 보여 준다. "설치는 버튼 하나, 그다음은 이렇게 된다"는 구성이다. 구독 연결은 설정 화면 안의 일이라 랜딩에서는 문장 하나로만 다룬다. Product Hunt 리뷰에는 연결 설정이 수월했다는 사용자 평이 있었지만 `[2차]`, 랜딩 자체는 설정 시간을 숫자로 약속하지 않는다.

### 1.6 모션과 인터랙션

번들 코드에서 확인한 수치다. `ease [0.22, 1, 0.36, 1]`은 빠르게 출발해 부드럽게 멈추는 곡선(ease-out 계열)이다.

| # | 장치 | 무엇이 어떻게 움직이나 | 트리거 | 수치 | 근거 |

### 1.7 타이포그래피, 색, 간격

- **글꼴**: 헤드라인은 자체 가변 글꼴(AsideDisplay)로 자간이 좁은 산세리프다. 본문은 Geist, 접속 기록 표는 Geist Mono. `[확인]` CSS
- **크기 위계(데스크톱, 캡처 기준 추정)**: 히어로 약 56px 두 줄, 섹션 제목 약 44px, 하위 제목 약 30px, 본문 18px, 카드 설명 16px.
- **색**: 글자는 거의 검정, 보조 문장은 중간 회색(neutral-500), 강조색은 하늘색 하나(sky-400·500). 파랑은 눈썹 링크, 벤치마크의 Aside 막대, 히어로·최종 CTA 배경에만 쓴다. 배경은 흰색과 아주 옅은 회색을 번갈아 쓴다. 비밀번호 Vault 배너 하나만 어둡다.
- **간격과 틀**: 본문 영역 양옆에 아주 옅은 세로선(검정 6% 투명도)을 그어 페이지를 하나의 기둥처럼 묶고, 섹션 사이는 점선으로 나눈다. 세로 여백은 md 이상에서 96px 수준으로 넉넉하다. 모서리 반경은 10px.
- **반복 패턴 두 가지**
  1. **눈썹 링크**: 섹션 제목 위 작은 파란 글씨 + `>` 화살표("Privacy and control >"). 라벨이면서 상세 페이지 링크다.
  2. **두 톤 문장**: 첫 문장은 검정 굵게, 이어지는 설명은 회색. 소개 단락과 모든 기능 카드에 똑같이 쓴다. 훑어보는 사람은 검정 글씨만 읽어도 요지를 잡는다.

## 2. 대비 사례

### 2.1 Opera Browser Connector (2026-04-16 발표)

- **방향이 반대다.** 구독을 브라우저로 가져오지 않는다. ChatGPT·Claude가 MCP로 브라우저에 연결되어 열린 탭과 페이지를 읽는다. 사용자는 ChatGPT·Claude 앱 안에 그대로 있다.
- **설명 방식**: 랜딩이 아니라 블로그 글이다. 순서는 소개 → 무엇인가 → 일상에서 어떻게 쓰나(용례 3개) → 켜는 법 → ChatGPT·Claude 연결 단계 → 다운로드. 설치 단계 스크린샷과 툴바에 고정된 확장 프로그램 스크린샷이 있다.
- **절차**: Early Bird 모드 켜기 → 재시작 → 설정에서 "AI Services" 검색 → 설치 → Opera 계정 로그인 → ChatGPT 또는 Claude 선택 → 각 AI 앱에서 안내대로 설정. 6단계가 넘는다. 시험 모드라는 마찰을 숨기지 않는다.
- **비용·신뢰**: "무료 기능"이라고 분명히 쓴다. ChatGPT·Claude 쪽 유료 플랜이 필요한지는 적지 않았다. 신뢰 장치는 **할 수 있는 것과 할 수 없는 것의 목록**이다. 탭 읽기·스크린샷은 기본 켜짐, 방문 기록·탭 닫기는 기본 꺼짐, 클릭·양식 입력은 하지 않음.
- **Experii에 주는 시사점**: "AI가 무엇을 보고 무엇을 안 보는지"를 켜짐·꺼짐 목록으로 적으면 신뢰가 생긴다. 다만 Experii가 무엇을 읽는지는 PRD에 아직 없다. 랜딩에 쓰려면 먼저 결정이 필요하다(4.4절).

### 2.2 ChatHub (chathub.gg)

- **방향이 또 다르다.** 지금 랜딩은 "구독 하나로 여러 모델"을 판다. 자기 구독(구조화 데이터 기준 Pro $19, Unlimited $39)을 파는 쪽이라, 쓰던 ChatGPT·Claude 계정이나 API 키를 쓸 수 있다는 말은 랜딩에 없다. `[확인]` WebFetch
- **히어로**: 큰 헤드라인과 CTA 3개, 모델 로고만 있다. 제품 화면, 시연, 단계 설명이 없다.
- **신뢰**: 사용자 수, 후기 6개, 평점, Product Hunt·Chrome 웹 스토어 링크. 프라이버시 언급은 없다.
- **Experii에 주는 시사점**: 반면교사다. 로고와 숫자만 있고 제품이 안 보이는 히어로는 "어떻게 쓰는지"를 전하지 못한다. Experii에는 후기와 사용자 수가 아직 없으니(PRD 5장) 이 방식은 쓸 수도 없다.

## 3. H4(구독 연동 가능성) 관련해 새로 확인한 사실

PRD H4는 `[확인필요]`다. 아래 내용은 **판단 근거가 아니라 확인할 때 볼 자료**로만 남긴다. 랜딩 문구는 이 절과 상관없이 TSD 6.3의 예정형을 유지한다.

| 대상 | 확인한 내용 | 상태 |
|---|---|---|
| Anthropic | Claude Code 법무·준수 문서(2026-10-26 조회)에 이런 내용이 있다. 소비자 플랜 OAuth는 Claude Code와 Anthropic 자체 앱의 일반 사용을 위한 것이다. 제3자 개발자는 API 키를 써야 한다. 제3자 앱이 Claude.ai 로그인을 제공하거나 사용자 대신 Free·Pro·Max 자격으로 요청을 보내는 것은 허용하지 않는다. 2026년 2월 무렵 이 방침을 명확히 했다는 보도도 여러 건 있다 | 공식 문서 `[확인]`, 시점 보도 `[2차]` |
| OpenAI | "Sign in with ChatGPT"가 2026-07 로그인 전용 베타로 시작했고, 2026-09-29 DevDay에서 Plus·Pro 구독 한도를 앱이 쓰는 권한이 추가됐다고 한다. 상업용 앱은 선정 파트너 한정 시범이라 관심 신청서를 내야 한다. 사용자가 앱별 주간 한도를 정할 수 있다. 이 권한은 사용자의 ChatGPT 대화나 메모리를 앱에 넘기지 않는다고 한다 | `[2차]` (OpenAI 원문 미확인) |
| Aside | 도움말에 ChatGPT Plus·Pro와 Claude Pro·Max를 OAuth로 연결한다고 적혀 있다. 이것이 위 Anthropic 문서와 어떻게 맞는지(별도 합의가 있는지 등)는 알 수 없다 | `[미확인]` |

**랜딩에 주는 영향**

- PRD H4 문장은 "구독 대화를 외부 앱에서 **읽는** 방식"이다. 그런데 위 자료로 보면, 가능성이 보이는 경로(OpenAI 구독 사용 권한)도 기존 대화를 읽는 것이 아니라 **Experii 안에서 새로 나누는 대화에 구독 한도를 쓰는 것**에 가깝다. 랜딩 시연은 "Experii 안에서 AI와 공부하는 장면"으로 그리고, "ChatGPT에서 하던 대화를 가져온다"는 장면은 그리지 않는 편이 안전하다. PRD 6장의 루프도 "앱 안에서 GPT·Claude와 SQLD 공부"라서 이쪽과 맞는다.
- "추가 비용 없음"을 쓰더라도, 2차 자료 기준으로 연결 앱들이 쓰던 구독의 사용 한도를 함께 쓴다. "무제한"으로 읽히는 표현은 피한다.
- Claude 쪽은 공식 문서와 충돌할 가능성이 있다. 랜딩에서 "Claude 연결"을 GPT와 같은 무게로 약속하는 것은 H4 확인 전까지 특히 조심해야 한다. 이 판단은 창업자 몫이므로 여기서는 사실만 적는다.

| B4 | 설정 경로를 문서에서 구체적으로 밝힌다(설정 > 모델 > 제공사 > 연결 > OAuth 팝업) | 연결 카드의 미니 화면을 "버튼 한 번 → 로그인 창 → 연결됨" 두세 컷으로 그린다. "로그인은 AI 회사 화면에서 한다"는 구조를 그림으로 보여 주면 비밀번호를 Experii에 넣는다는 오해를 줄인다. 단, 실제 방식이 정해지기 전이므로 예시 배지와 예정형 문구를 붙인다 | H4 `[확인필요]` |
| B5 | 같은 주 CTA를 히어로·내비·최종 CTA에 반복한다 | 섹션 6 끝에 "사전 신청하기" 버튼(→ `#signup`)을 한 번 더 둔다 | PRD 10장 #7 |
| B6 | 설정 시간을 숫자로 약속하지 않는다 | "3분"은 측정 전이라 TSD 6.3대로 "3분 안에 시작하도록 만들고 있어요"로 쓰거나 숫자를 뺀다. Aside도 숫자 없이 버튼 하나로 마찰이 낮다는 인상을 준다 | PRD F1 목표치, TSD 6.3 |
| B7 | 눈썹 링크(작은 강조색 라벨 + `>`) | 섹션 6 제목 위에 "귀찮지 않은 시작" 라벨. 섹션 1~6에 같은 패턴을 쓰면 긴 한 페이지가 읽기 쉬워진다 | PRD 7장 톤 키워드 "귀찮지 않은" |

**섹션 6 배치 초안 (데스크톱)**

```
[라벨] 귀찮지 않은 시작 >
[제목] 연결하고, 공부만 하세요            ← 예시. 확정 카피 아님
[카드 1: 가입 미니 화면]  [카드 2: 내 AI 연결 시트 + 준비 중 칩]  [카드 3: SQLD 첫 질문 입력창]
  굵은 라벨 + 회색 한 줄     굵은 라벨 + 회색 한 줄               굵은 라벨 + 회색 한 줄
[작은 글씨] Experii 이용료는 받지 않아요. AI는 쓰고 있는 구독을 그대로 써요.
[버튼] 사전 신청하기
```

모바일에서는 카드 3장을 세로로 쌓거나 Aside 사용 사례 카드처럼 가로 스와이프로 넘긴다. 3단계는 순서가 중요하니 세로 쌓기와 번호 표시를 권한다.

### 4.2 제품 화면 데모 ("Experii 안에서 GPT와 공부하는 화면")

사용자는 랜딩에서 "SQLD 공부 대화 → 현장 과제 → 면접 답변 한 줄 저장 → 리마인드" 루프를 Experii 화면 하나로 보여 주기를 원한다. Aside 히어로 시연이 바로 이 형식, 즉 **코드로 그린 실제 같은 화면에서 한 가지 일이 처음부터 끝까지 일어나는 장면**이다.

**가져올 것**

| # | Aside 장치 | Experii 적용 |
|---|---|---|
| D1 | 영상이 아니라 HTML·코드로 그린 시연 | 폰 프레임 안을 HTML/CSS로 그린다. 글자가 선명하고, 문구를 `content/loop.ts`에서 바꿀 수 있고, 가볍다. TSD 6.2 "이미지 아님"과 같다 |
| D2 | 일상적이고 조금 귀찮은 과제 하나(안 쓰는 구독 해지·환불)를 끝까지 보여 준다 | SQLD 수험생이 실제로 헷갈려하는 질문 하나(JOIN 차이)를 끝까지 보여 준다. TSD 6.2 예시 데이터를 그대로 쓴다 |
| D3 | 요청 문장 한 글자씩 입력, 답변 단어 단위 등장 | 사용자 질문은 한 글자씩, AI 답변은 어절 단위로 나타나게 해서 "GPT와 대화 중"이 한눈에 보이게 한다 |
| D4 | 단계 줄이 아이콘과 함께 하나씩 나타남("기록 검색", "사이트 열기"…) | "대화에서 개념 찾기: LEFT JOIN" → "실무 상황 고르기: 쇼핑몰 주문 테이블" → "현장 과제 만들기" 같은 줄이 하나씩 뜬다. PRD 근거 1(대화 맥락에서 바로 과제를 낸다)을 눈으로 보여 주는 장치다 |
| D5 | "작업 중 N초" 라벨의 반짝이는 그라데이션 | "과제 만드는 중…" 라벨에 같은 효과를 준다 |
| D6 | 오른쪽 패널이 열리며 결과물이 옆에 쌓인다 | 폰 화면에서는 아래에서 올라오는 시트로 바꾼다. 현장 과제 카드 → 사용자 풀이 → "경험 카드로 저장" |
| D7 | 끝나면 새 탭으로 돌아와 "Recent tasks"에 방금 작업이 추가됨 | 끝나면 홈으로 돌아와 "내 경험 카드" 목록 맨 위에 방금 카드가 꽂히고, 잠금화면 알림 "1일 뒤"가 내려온다. 쌓인다는 USP(PRD 5장)를 마지막 컷으로 남긴다 |
| D8 | 일시정지·재개·다시 보기 버튼과 접근성 라벨 | 자동 재생을 쓴다면 반드시 붙인다(WCAG 2.2.2). 동작 줄이기 설정이면 마지막 장면을 정지 화면으로 보여 준다 |
| D9 | 요청 말풍선을 결과 화면 위에 얹은 사용 사례 카드 | `LoopStepper` 4개 패널마다 위에 사용자의 말 한 줄, 아래에 그 결과 화면을 둔다. 예: "LEFT JOIN이랑 INNER JOIN 차이가 헷갈려" → 학습 대화 화면 |

**스토리보드 초안 (자동 재생을 고를 경우, 약 14초)**

| 시점 | 장면 | 움직임 (Aside 수치 참고) |
|---|---|---|
| 0.0s | Experii 홈. 입력창에 `SQLD` 칩 | 정지 |
| 0.5s | 손가락(탭 표시)이 입력창으로 | 약 0.9초 이동 |
| 1.5s | "LEFT JOIN이랑 INNER JOIN 차이가 헷갈려" 입력 | 한글은 음절당 약 50ms를 권한다. Aside의 34ms는 영문 글자 기준이라 한글에서는 너무 빠르게 읽힌다 `[제안]` |
| 2.8s | 사용자 말풍선, AI 답변이 어절 단위로 등장 + 예시 테이블 두 개 | 어절당 약 60ms |
| 5.0s | 단계 줄 3개가 0.35초 간격으로 등장 | 위에서 10px 내려오며 투명도 0→1, 0.32초, ease `[0.22,1,0.36,1]` |
| 6.5s | 현장 과제 카드가 아래에서 올라옴 | 시트 슬라이드 0.4초 |
| 8.0s | 풀이 `LEFT JOIN … WHERE o.id IS NULL` 입력 | 코드 글꼴, 글자당 약 30ms |
| 10.0s | "경험 카드로 저장" 탭 → 카드가 한 줄 답변으로 접힘 | 높이·크기 전환 0.4초 |
| 11.5s | 홈으로 돌아가 "내 경험 카드" 맨 위에 꽂힘 | Aside의 "Recent tasks" 복귀 장면과 같은 역할 |
| 12.5s | 잠금화면 알림 "1일 뒤 · 어제 배운 점: LEFT JOIN은 왼쪽 표의 행을 모두 남겨요" (TSD 6.2의 1일 뒤 = 배운 점) | 위에서 내려오는 알림 0.3초 |
| 14.0s | 정지 + 다시 보기 버튼 | 자동 반복하지 않는다(Aside도 끝나면 다시 보기만 보여 준다) |

**TSD와의 조율점**: TSD 6.2는 `LoopStepper`를 "사용자가 누를 때만 진행, 자동 진행 없음"으로 정했다. 위 스토리보드는 (a) 히어로나 섹션 4 위의 별도 시연 블록에 일시정지·다시 보기를 붙여 자동 재생하는 안, (b) 같은 장면을 `LoopStepper` 탭 4개에 나눠 담는 안, 둘 다에 쓸 수 있다. 어느 쪽인지는 디자인 에이전트가 정하고, 정하지 않으면 TSD가 우선이다.

**표현 주의**

- 입력창에 Aside처럼 모델 이름 칩("GPT-6 · High")을 그대로 넣으면 연동이 이미 된다는 뜻이 된다. H4 확인 전에는 "AI" 같은 중립 표기나 "내 AI 연결 예정" 칩을 쓴다.
- 모든 프레임에 `예시 화면` 배지를 붙인다(TSD 6.2).
- 경험 카드에 세션에 없는 성과 수치를 넣지 않는다(TSD 6.2).

### 4.3 피할 것

| Aside의 표현·장치 | 피하는 이유 | 대안 |
|---|---|---|
| "가장 똑똑한 AI 비서" 같은 최상급 헤드라인 | PRD 7장: "최고"류 단정 표현 금지 | 히어로는 PRD 10장 후보처럼 Before→After로 쓴다 |
| "SOTA", "#1", 경쟁사를 이겼다는 벤치마크 막대 | PRD 7장: "1위"·비교 표현 금지, 경쟁사 깎아내리기 금지. Experii에는 측정 자료도 없다 | 증거 대신 실제 같은 예시 화면과 고객이 한 말(PRD 3장 원문)을 쓴다 |
| "지금의 AI 브라우저는 고장 났다"는 카테고리 비난 | PRD 7장, TSD 6.1 #5(경쟁사 실명 금지). 섹션 3 "시대 변화"도 질문형으로 쓰기로 했다 | "서류는 AI가 도와줘요. 면접에서 나누는 대화는요?"(TSD 6.1 #3) |
| "브라우저에서 하는 일은 무엇이든", "한계는 상상력뿐" | 보장·무제한으로 읽힌다(PRD 7장 취지, TSD 금지어 '무조건'·'100%') | 할 수 있는 일을 SQLD 한 과목, 루프 4단계로 좁혀 말한다 |
| 쓰던 구독 연결을 이미 되는 일처럼 쓰는 문장 | H4 `[확인필요]`. 3절의 Anthropic 공식 문서와 충돌할 수 있다 | TSD 6.3 예정형 "연결할 수 있게 준비하고 있어요" |
| AI 제공사 로고를 궤도처럼 둘러 배치 | 제휴나 공식 지원처럼 보일 수 있다. 각 사 상표 사용 지침은 따로 확인해야 한다 `[확인필요]` | 로고 없이 "GPT·Claude" 글자로 쓴다 |
| 로컬 저장, 하드웨어 암호화, "LLM 제공사와 공유하지 않음" 같은 보안 주장 | Experii의 데이터 처리 방식은 PRD에 없다. 쓰던 구독을 쓰는 구조라면 대화는 AI 제공사로 가는 것이 기본이라 같은 문장을 쓸 수 없다 | 데이터 처리 방식이 정해지면 그때 쓴다(4.4 Q2). 지금은 TSD 13장 개인정보 문구 범위만 쓴다 |
| YC 배지, 사용자 수, 평점 | Experii에는 아직 없다(PRD 5장 "후기 근거 없음"). 지어내면 안 된다 | 사회적 증거 자리를 비우거나 "SQLD 공부 중인 대학생 먼저 모집" 같은 사실만 쓴다 |
| 832px 고정 높이 히어로 시연, 약 2.4MB JS + 약 690KB Rive | 모바일 첫 화면을 시연이 다 차지한다. TSD 12장 성능 예산과 "LCP는 히어로 제목" 원칙에 맞지 않는다 | 시연은 히어로 제목 아래나 섹션 4에 두고 화면에 들어올 때 불러온다. Rive·WebGL 없이 CSS 전환으로 만든다 |
| 화면에 들어올 때마다 다시 재생(아이콘 벽 once: false) | 스크롤을 오르내릴 때마다 움직여 산만하다 | 화면 진입 시 한 번만 실행한다 |
| 영어 전제 타이포(좁은 자간 디스플레이 글꼴) | 한글은 같은 자간이면 답답해진다 | 한국어 글꼴과 줄 간격은 토스 분석을 따른다 |
