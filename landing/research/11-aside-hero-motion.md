## 시간 흐름 (자동 재생, 루프 아님)
| 시각 | 무엇이 |
|---|---|
| 0~1s | 첫 상태 정지. 커서 아이콘이 입력창 위에 있다(사용자가 준 캡처 1) |
| ~3s | 입력창에 작업 문장이 한 글자씩 타이핑된다 |
| ~5s | 전송 → 사이드바 Chats 맨 위에 새 대화가 생기고 본문이 대화 화면으로 바뀐다(주소창 줄에 대화 제목) |
| 5~12s | 대화 본문에 단계 줄이 하나씩 쌓인다(아이콘 + 회색 동사 + 파란 링크), 접히는 결과 카드, 오른쪽에 에이전트 탭 미리보기 카드가 겹쳐 뜬다 |
| 끝 | 멈춘다. `Replay illustration animation` 버튼(aria-label)으로 다시 볼 수 있다 |

- 영상(`<video>`)이 아니라 DOM으로 그린 일러스트다(`document.querySelectorAll('video')` 0개). 실행 중 `document.getAnimations()` 2개.
- 스크롤은 평범하다(sticky 요소 1개). 스크롤 연동 연출은 거의 없고, 창 아래 끝이 카드 경계에서 잘려 "더 있다"를 암시한다. 그 아래 섹션은 흰 바탕 `Introducing Aside >` + 두 톤 문단.

## Experii에 옮길 원리 (코드·에셋·카피 복사 금지, 원리만)
- 히어로 = 가운데 제목 + 다운로드 버튼 + **Experii 데스크톱 앱 창**. 창 안에서 SQLD 질문이 타이핑되고, 대화 → 현장 과제 → 커서가 보기를 누름 → 경험 카드 저장 → 데스크톱 알림(1·7·30일)으로 이어지는 **한 컷 루프**를 자동 재생한다.
- 커서(포인터 아이콘)가 실제로 움직여 버튼을 누르는 모습 + 누를 때 퍼지는 원(탭 피드백). 사용자 요청 "메인 화면에서 터치를 하는 움직임".
- 재생은 한 번만, 끝나면 정지 + `다시 보기`. 재생 중 `일시정지` 버튼 상시 노출(WCAG 2.2.2, 5초 초과 자동 움직임).
- 첫 프레임은 의미 있는 정지 화면(빈 창 금지). 동작 줄이기·JS 없음이면 마지막 상태 정지.
