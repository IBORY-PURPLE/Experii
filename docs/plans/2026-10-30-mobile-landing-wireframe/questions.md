## 블록별 질문

각 질문 끝의 괄호가 근거다. "R"은 어제 점검 `report.md`, "C"는 기준표 `criteria.md`.

### 1. 후킹 (첫 화면 390×844)
1. 이게 뭐예요? → "Experii AI Board" + "대학생을 위한 AI 면접 역량 도우미" (창업자 결정. R 1절: 포지셔닝 E5는 첫 화면에 있을 때 잘 읽혔다)
2. 무슨 일이 일어나는지 바로 보여요? → 보드가 첫 화면 안에서 움직이기 시작해야 한다 (1쪽 요약 성공 기준 1)
3. 지금 쓸 수 있어요? → 첫 화면에 "Windows 앱 · 출시 전, 사전 신청" (R 6절: 12/12가 출시 전으로 읽음. 지켜야 할 장점)
4. 나 같은 사람 얘기예요? 과목이 정해져 있어요? → "AI로 공부하는 모든 과목" 한 줄. SQL은 "예시" 표시 (R 5절: 12/12가 과목을 좁혀 읽음. C E1 확정 기준)

### 2. 상황 (L1 인정)
1. 나도 GPT로 공부하는데, 그걸 바꾸라는 거예요? → 아니다. 쓰던 GPT 그대로 (C L1, E12. R 2절: L1은 잘 들어간 고리)
2. 어떤 공부에 맞아요? → 대학 수업, 자격증, 자료를 모으며 하는 공부. SQL은 예시 (C E1. R 7절 고칠 곳 2)

### 3. 문제 (L2 흩어짐, L3 안 남음)
1. 뭐가 문제인데요? → 대화가 늘수록 흩어지고 저장만 하고 다시 안 본다 (C L2. R 2절: '흩어' 0건, L2 짚음 3/12)
2. 공부했으면 됐지 면접이랑 무슨 상관이에요? → 면접에서 "GPT로 공부했어요"는 경험으로 안 들린다 (C L3, E4)
3. 고객 말로 보여 줄 수 있어요? → "노션과 카톡에 누적만 되고 다시 안 봄" 같은 실제 말 (C E13)

### 4. 해결 (L4 해법, 보드 움직임 5장면)
1. Experii에서는 뭘 해요? → GPT 대화 → 답의 글을 끌어 필기 → 대화 하나가 필기 섹션 → 섹션 맨 앞 경험 카드 → 로드맵 칸 (flow-v2 0장)
2. 공부를 앱 안에서 해요, GPT 앱에서 해요? → Experii 안에서 내 ChatGPT로 대화한다 (R 5절: 4/12가 헷갈림)
3. 필기를 내가 다시 써야 해요? → 아니다. 답의 글을 끌어 놓으면 원문 그대로, 몇 번째 질문인지 붙는다 (flow-v2 핵심 3)
4. 이게 실제 화면이에요? → 아니다. "개발 중인 화면 · 예시" 표시 (창업자 결정. R 6절 정직성 경고)

### 5. "그냥 GPT 쓰면 되잖아요?" (E9)
1. GPT한테 "면접 답변으로 정리해 줘" 하면 되지 않아요? → 한 번은 된다. 하지만 대화창은 날짜·과목·내가 고른 핵심을 쌓아 두지 않는다. AI Board는 같은 GPT 위에 필기·카드·로드맵을 쌓는다 (R 5절: 8/12가 이 반문. C E9 확정 기준)
2. PDF로 저장해 두는데 뭐가 달라요? → 저장한 파일은 다시 안 연다(L2). 카드는 과목 로드맵에서 날짜 순으로 다시 열린다 (R 5절: biz4 2명)
3. 경쟁 앱 욕하는 거예요? → 아니다. GPT를 경쟁자로 두지 않고 "대화창 vs 칠판"으로 맞댄다 (C E15, L1)

### 6. 안심
1. 내 ChatGPT 비밀번호를 넘겨요? 대화를 통째로 가져가요? → "Continue with ChatGPT"로 OpenAI 화면에서 로그인한다. 대화·필기·카드는 내 PC에만 저장, Experii 서버 없음 (R 5절: 12/12 걱정. 데스크톱 PRD 5·8장)
2. 돈은요? → 쓰던 ChatGPT(Plus·Pro)로 쓴다. Experii 이용료 문구는 기존 랜딩과 같게 두되 출시 때 확정 (R 5절: 폰 9/9 "돈 얘기 안 보임". `landing/content/landing.ts:128`)
3. 이미 모아 둔 GPT 대화·PDF를 가져와요? → 첫 버전은 Experii에서 새로 나눈 대화부터 쌓인다 (R 5절: 8/12 질문. flow-v2 "바깥 글 받지 않음")
4. 폰에서 써요? → Windows 앱이다. 폰은 신청만 (데스크톱 PRD 6장 "모바일" 제외)
5. 면접 연습은요? → "출시 뒤" 블록에 따로: 면접 문장 연습, 다시 꺼내 주기(리마인드), 실무 과제 (창업자 결정. R 6절, 8절: 12/12가 연습을 못 읽음. v1에 없으니 출시 뒤로)

### 7. 신청
1. 무엇을 받게 돼요, 언제? → "출시하면 다운로드 링크를 이메일로 보내 드려요" (1쪽 요약 위험 3. `landing.ts:52`)
2. 버튼이 몇 개예요? → 사전 신청 하나 (창업자 결정)
3. 폰으로 신청하고 PC에서 받으려면? → 이메일로 받은 링크를 PC에서 연다 (레퍼런스 조사로 보강)
