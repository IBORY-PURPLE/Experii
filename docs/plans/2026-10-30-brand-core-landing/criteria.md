# 점검 기준표 (1단계)

> 출처: 브랜드 코어 카드(`Experii_brand-core-card.md`, 2026-10-26)와 창업자가 2026-10-30에 밝힌 서비스 목표. 둘이 다르면 서비스 목표를 우선한다(1쪽 요약 결정 1, 추천안).
> 상태: 2026-10-30 창업자 확인 끝. 아래 "확인 뒤 바뀐 기준 문장"이 위 표보다 우선한다.

## 반박의 네 고리

반문: "그냥 GPT 앱에서 하면 되는 거 아니에요?"

| 고리 | 기준 문장 | 랜딩에서 찾을 신호 |
|---|---|---|
| L1 인정 | 범용 AI로 공부하는 건 맞다. Experii도 쓰던 GPT를 그대로 쓴다 | GPT를 경쟁자로 두지 않고 "쓰던 걸 그대로"라고 말함 |
| L2 흩어짐 | 프로젝트·세션이 늘수록 흩어지고, 저장만 하고 다시 안 본다 | 저장만 하고 안 보는 장면, 흩어진 대화·파일 |
| L3 안 남음 | 퀴즈 풀고 답 맞히는 공부는 면접에서 "써 봤다"는 경험이 되지 않는다 | 공부했지만 면접에서 꺼낼 게 없는 장면 |
| L4 해법 | 학습 세션을 날짜·시간·경험으로 쌓고, 면접 문장으로 바꿔 연습시켜 현업 적용 역량을 증명하게 한다 | 쌓이는 기록, 면접 문장, 연습, "이렇게 써 봤어요" |

## 브랜드 코어 15개 요소

| 요소 | 기준 문장 | 카드와 서비스 목표의 차이 |
|---|---|---|
| E1 타깃 | AI로 SQLD 같은 자격증을 공부하는 취업 준비 대학생 | 목표는 SQL·AI 역량 등 모든 면접. 랜딩 v0.1은 SQLD 한정 |
| E2 문제 | 공부는 했는데 면접에서 꺼낼 경험으로 남지 않는다("이게 면접에 쓸모 있을까") | 목표가 원인을 더함: 세션이 늘수록 흩어지고 다시 안 본다(L2) |
| E3 해결 | AI와 공부한 대화를 면접용 경험으로 정리한다 | 목표가 더함: 면접 문장으로 바꿔 연습시킨다 |
| E4 Before→After | "자격증 있어요" → "이런 과제에서 이렇게 써 봤어요" | 목표: 현업에 바로 적용할 역량의 증명 |
| E5 포지셔닝 | 면접에 집중한 학습 앱 | 같음 |
| E6 본질 | 공부가 경험으로 남는다 | 같음 |
| E7 USP 키워드 | 쌓아 둔 걸 다시 꺼내 준다 | 같음(L2의 답) |
| E8 톤 | 귀찮지 않은 | 목표에 언급 없음 |
| E9 USP 차별 | 카드: 지원 직전 서류 도구(TIO·자소설닷컴)와 달리 공부하는 날마다 쌓는다. 몇 달 치 기록은 나중에 거꾸로 만들 수 없다 | 목표: 가장 큰 비교 대상은 GPT 직접 사용 |
| E10 근거 1 | 공부 대화 맥락에서 현장 과제를 내고, 푼 결과를 면접 답변 한 줄로 저장 | 목표의 수단은 프로젝트 폴더 파일 화면(요점·학습 기록·날짜·시간·경험). 현장 과제는 데스크톱 v1에 없음 |
| E11 근거 2 | 1·7·30일 리마인드로 배운 점·활용 방안·면접 예시 답변을 다시 꺼내 줌 | 데스크톱 v1에 없음(출시 예정 표시 있음) |
| E12 근거 3 | 이미 구독 중인 GPT·Claude 연동, 별도 구독료 없음 | 목표: 범용 AI·GPT 프로젝트 폴더 |
| E13 고객 언어 | "공부 시간은 늘었는데 이해도는 떨어지는 느낌", "노션과 카톡에 누적만 되고 다시 안 봄", "웹 리서치 시간이 너무 아까움", "필요는 한데 어떻게 만들건데?" | 목표의 창업자 경험(폴더를 학습장으로 써 봤지만 다시 안 봄)이 같은 결 |
| E14 말투 | 같은 과 선배가 알려 주듯 짧고 친근한 존댓말, 용어는 풀어서, 세팅이 쉽다는 느낌 | 같음 |
| E15 금지 표현 | 성과 보장("면접 준비 끝", "합격 보장", "1주일 만에 합격"), 단정("최고·1위·유일"), 경쟁사 비방, 광고 표시 없는 대가성 후기 | 같음 |

## 일부러 다르게 쓴 곳 (결함으로 세지 않음)

창업자 확인으로 정한다. 후보:

| 후보 | 랜딩의 모습 | 이유 추정 |
|---|---|---|
| D1 "3분 세팅" 제외 | "가입은 짧게"로만 씀 | 출시 전이라 시간을 약속할 수 없음 |
| D2 "1년 치" 제외 | "몇 달 치 기록"으로 씀 | 출시 전 서비스라 1년 치 기록이 있을 수 없음 |
| D3 Claude 미표기 | 연동은 ChatGPT만, Claude는 신청서 선택지에만 | 첫 버전 연동이 ChatGPT 로그인 하나 |
| D4 경쟁사 이름 미표기 | "지원할 때 쓰는 도구"로 씀 | 경쟁사 비방 금지 |
| D5 SQLD 한정 | 모든 면접이 아니라 SQLD 하나 | 랜딩 v0.1의 첫 과목 |

## 창업자 확인 결과 (2026-10-30)

| 질문 | 창업자 답 | 기준표에 반영한 것 |
|---|---|---|
| USP 차별(E9) 비교 대상 | "GPT를 내 데스크톱 앱에 OAuth로 연결하고 내 앱의 MCP, 플러그인 툴들을 개발해서 넣을 예정" | 비교 대상은 GPT 직접 사용. 차이의 근거는 "같은 GPT를 Experii 안에 연결하면 Experii의 도구가 공부를 경험으로 쌓고 면접 문장으로 바꾼다"이다 |
| 해결 방식(E3·E10·E11) | 목표 흐름, 수단은 예시 | 세션이 경험으로 쌓임 → 면접 문장 → 연습이 보이면 맞음. 현장 과제·리마인드는 예시로 보고 정직성만 따로 본다 |
| 일부러 다르게 쓴 곳 | "일단 GPT 연동으로 가고, 학습과 실제 역량을 연결해 준다고 하고, SQLD 한정이 아니라 AI로 공부할 수 있는 모든 과목을 스스로 선정할 수 있다. 대학 공부, 레퍼런스를 스스로 모을 수 있는 공부는 다 가능" | D3(Claude 미표기)은 의도된 차이. D5(SQLD 한정)는 의도된 차이가 아니다. 과목은 사용자가 고르고 SQLD는 예시일 뿐이다. 핵심 메시지는 "학습과 실제 역량을 연결" |
| 목표에 있고 PRD·랜딩에 없는 것 | PRD 판단 필요로 따로 | 면접 연습, 프로젝트 폴더 파일 화면은 결함으로 세지 않고 판정표 끝에 따로 적는다 |

답이 없던 D1("3분" 제외)과 D2("1년 치" 제외)는 출시 전이라 약속할 수 없는 숫자라서 의도된 차이로 둔다. 창업자가 아니라고 하면 바꾼다. D4(경쟁사 이름 미표기)는 금지 표현 규칙이라 자동 포함이다.

### 확인 뒤 바뀐 기준 문장

| 요소 | 확정 기준 |
|---|---|
| E1 타깃 | AI로 공부하는 대학생·취업 준비생. 과목은 스스로 고른다(대학 수업, 자격증, 레퍼런스를 모을 수 있는 공부). SQLD는 예시 |
| E3 해결 | 쓰던 GPT로 공부한 세션이 경험으로 쌓이고, 면접 문장으로 바뀌어 연습까지 이어진다 |
| E4 Before→After | "자격증 있어요" → "이런 과제에서 이렇게 써 봤어요". 학습과 실제 역량이 연결된다 |
| E9 USP 차별 | GPT 앱을 따로 쓰면 세션이 흩어지고 다시 안 본다. 같은 GPT를 Experii에 연결하면 Experii의 도구가 공부를 경험으로 쌓고 면접 문장으로 바꾼다. 지원 직전 서류 도구와의 비교는 보조 |
| E12 근거 3 | 쓰던 ChatGPT를 연결한다(추가 구독료 없음). Claude는 표기하지 않아도 된다 |
| L1 인정 | 범용 AI(GPT)로 공부하는 건 그대로다. Experii는 그 GPT를 연결해 쓴다 |
| L4 해법 | 학습 세션을 날짜·시간·경험으로 쌓고 면접 문장으로 바꿔 연습시켜, 학습과 실제 역량을 연결한다 |

### PRD 판단 필요 (판정표 끝에 따로 적을 것)

- 랜딩 PRD v0.1은 "첫 과목은 SQLD"(F2)와 "SQLD 공부 중인 대학생 우선"(CTA)으로 SQLD를 앞세운다. 데스크톱 PRD는 과목을 사용자가 만든다(FR-02). 창업자 의도(모든 과목)와 랜딩 PRD가 다르다.
- 면접 연습, 프로젝트 폴더 파일 화면, Experii의 MCP·플러그인 도구는 서비스 목표에 있고 PRD에는 없다.
