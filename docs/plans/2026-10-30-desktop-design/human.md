# 데스크톱 화면 디자인 통일 (1쪽 요약)

**영역·단계:** 데스크톱 앱, MVP v1(창업자 PC에서 2주 써 보며 H2 검증). 기능은 그대로 두고 겉모습만 바꾸는 일이라 범위 안이다. PRD는 세부 화면을 시안 3개 중 고른 안으로 정한다.

**목표:** 로고·색·버튼·대화 상자를 한 규칙으로 묶어 Aside처럼 조용하고 깔끔하게 만든다. 로드맵 길만 Experii다운 자리로 남긴다.
**결과물:** 디자인 규칙 한 장, 그 규칙을 따르는 앱 화면, Experii 로고, 창·작업 표시줄·설치 파일 아이콘, 전후 스크린샷
**지금 문제:**
- 색이 꽉 찬 버튼이 다섯 가지 색이고, 강조색 네 가지가 한 화면에서 다툰다.
- 모서리 13가지, 글자 크기 9가지, 굵기 8가지, 그림자 9가지를 부품마다 따로 정했다.
- 세 구역의 맨 윗줄 높이가 서로 다르다.
- 로고가 정해지지 않았다. 앱 아이콘은 개발 도구 기본이고, 앱 이름은 'desktop'이다.

**방향 (Aside에서는 원리만 가져온다)**
- 흰 바탕에 검정·회색 글자, 강조색 하나. 중요도는 굵기보다 글자 크기와 회색 단계로 나눈다.
- 굵은 테두리와 튀어나온 그림자 대신 옅은 윤곽선과 그림자. 모서리·간격·높이는 몇 단계로만 쓴다.
- 색이 꽉 찬 버튼은 한 화면에 하나. 로고는 작게 두고, 빈 화면에만 옅게.
- 입체 칸과 강조색은 로드맵 길에 모은다. 이곳이 Experii다운 자리다.

**방법** (설치본 단계 전에 끝낸다)
1. **시안 고르기** (AI 1일, 창업자 30분): 화면 전체 방향 3개와 로고 3개를 만든다. 같은 세 장면(카드를 펼친 메인, 다시 만들기 대화 상자, 첫 실행 빈 화면)을 창 틀까지 그리고, 방향마다 배치나 중요도 순서를 다르게 한다. 창업자는 내장 브라우저에서 실제 크기로 보고 고른다.
2. **화면 통일** (AI 2일, 창업자 20분): 고른 방향의 공통 값을 한 곳에 모은다. 경험 카드·로드맵·대화부터, 그다음 버튼·입력창·대화 상자·사이드바를 바꾼다. 창업자는 전후 비교를 본다.
3. **로고·앱 아이콘** (AI 1일, 창업자 20분): 작은 크기용까지 다듬어 창·작업 표시줄·설치 파일에 넣는다. 창업자는 설치해서 본다.
4. **검증** (AI 반나절, 창업자 15분): 실제 앱 창에서 Windows 밝은·어두운 테마, 글자 대비, 키보드 위치 표시, 움직임 끄기 설정, 자동 테스트를 본다.

**하지 않는 것**
- 새 기능
- B안의 배치와 카드 중심 순서, 로드맵 칸 배치, 정해진 문구, 글꼴, 어두운 테마
- Aside의 로고와 닮은 모양, 글꼴, 아이콘, 코드, 문구, 하늘색 배경
- 랜딩페이지는 로고가 정해진 뒤 따로 맞춘다.

**정해 줄 것** (괄호는 추천, 답이 없으면 추천으로 간다)
1. **10월 29일 B안의 모양을 얼마나 바꾸나:** 전부 / 일부 / 안 바꿈 (일부: 칸의 입체와 파랑·초록·호박 색 값은 지키고, 타일·카드·버튼으로 번진 입체와 색만 걷어 낸다)
2. **강조색:** 호박 / 파랑 (호박: 경험이 쌓이는 자리의 색이고, 어두운 작업 표시줄에서도 보여 아이콘에 쓸 수 있다. 시안에서 파랑과 나란히 비교한다)
3. **앱 이름:** Experii / Experi (Experii: 로고와 설치 폴더 이름이 이걸로 정해지니 로고 시안 전에 필요하다)
4. **무료 디자인 도구 impeccable·prototype 설치:** 예 / 아니오 (예: 실제 앱 창을 검사하는 유일한 도구다. 자동 실행과 사용 기록 전송은 끄고 쓴다)

**결정 (2026-10-30 창업자):**
1. 답 없음 → 추천대로 일부
2. 파랑. 호박은 빼고, 화면의 주 색은 파랑과 검정만 쓴다.
3. Experii
4. 설치. 설치 뒤 두 도구를 써서 진행한다.

**비용:** 창업자 약 1.5시간, AI 약 4~5 작업일, 돈 0원

**성공 기준**
- 강조색은 경험이 쌓이는 자리(완료 칸, 카드 띠, '경험으로 남기기')에만 보인다.
- 같은 뜻은 같은 모양이다. 색이 꽉 찬 버튼은 한 화면에 하나다.
- 메인 화면을 5초 보고 '지금 누를 것'과 '방금 쌓인 경험'을 바로 짚는다.
- 이름을 가려도 Aside가 아니라 Experii로 보이고, 창·작업 표시줄·설치 아이콘이 Experii 로고다.

**위험**
1. **2주 사용 시작이 며칠 늦어진다.** 대신 첫 설치부터 이름·아이콘·화면이 확정되고, 쓰는 동안 화면을 바꾸지 않는다.
2. **진행 중인 로그인 작업과 같은 화면 파일을 고친다.** 시안은 바로 시작하고, 코드는 로그인 작업이 합쳐진 뒤 고친다.
3. **외부 도구가 실행 파일과 자동 실행 장치를 들여온다.** 자동 실행은 끈 채로 시작하고, 문제가 생기면 지운다.
