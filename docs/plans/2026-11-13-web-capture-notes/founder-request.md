## 0. 한 줄 목표

일반 유저가 URL로 Experii를 써 보게 하고, **화면/이미지 캡쳐를 보드에 올리면 Claude가 필기를 자동 생성**하게 한다.

## 1. 배경 (고정 맥락 — 수정 최소화)

- 기존: `apps/desktop/` Electron + React + TypeScript. 핵심 루프 = 공부(GPT) → 필기 → 경험 카드 → 로드맵.
- 현재 필기(FR-16): GPT **답 텍스트를 드래그**해 보드에 놓는 방식. 원문 그대로 저장.
- 현재 데이터: PC 로컬 SQLite. Experii 서버 없음. ChatGPT 로그인 기준.
- 미룸(데스크톱 PRD): GPT가 필기를 **다듬어 주는** 기능.
- 이번 요청: 데스크톱 기능을 **웹으로 이식·공개** + **캡쳐 업로드 → Claude Vision 기반 자동 필기** + **Vercel 배포**.

### 4.1 Claude 연동 제약 (확정)

- 개발 중 AI/에이전트는 **실제 Anthropic API를 호출하지 않는다.** `ANTHROPIC_API_KEY` 실값을 넣거나 요구하지 않는다.
- 대신 `generateNotesFromCapture(image) → NoteBlock[]` 같은 **단일 인터페이스**와 목 구현을 둔다.
- 목은 5장 스키마와 같은 JSON을 반환하고, 지연·실패 케이스도 흉내 낼 수 있게 한다.
- 실연동 시 목만 갈아끼우면 되도록 어댑터/라우트 경계를 둔다. 키는 서버 env만.
- 실 Claude API 키 연결·검증은 **창업자가 내일 아침** 한다.

## 5. 필기 생성 규칙 (초안 — 여기서 확정)

데스크톱 FR-16과 충돌하지 않게 **새 경로**로 둔다:  
`source = drag-from-chat | capture-vision`

### 5.1 출력 단위

한 캡쳐 → 필기 블록 **여러 개** 가능. 각 블록:

| 필드 | 필수 | 설명 |
|---|---|---|
| `text` | O | 보드에 보이는 필기 본문 (한국어) |
| `kind` | O | `concept` \| `step` \| `quote` \| `warning` \| `todo` \| `other` |
| `source_region` | 권장 | 이미지 위 대략 위치 (예: top/middle/bottom 또는 bbox) |
| `confidence` | 권장 | 0~1. 낮으면 UI에서 흐리게/확인 유도 |
| `raw_excerpt` | 선택 | 이미지에서 읽은 원문(OCR 성격). `text`와 다를 수 있음 |
