# 웹 앱 공개 실험: 캡쳐를 붙이면 AI가 필기해 주는 Experii

> 2026-11-13 03:10 창업자가 "계획 수립하고 진행해줘"로 미리 승인했다(작업 프롬프트: `founder-request.md`). 아래 "정해 줄 것"은 추천안으로 진행한다. 바꾸고 싶으면 아침에 말해 주면 된다.

**PRD 영역과 단계:** 앱 영역, 지금은 데스크톱 MVP v1 단계다. 웹 앱은 원래 범위 밖이었는데, 창업자가 작업 프롬프트에서 "PRD 정식 개정"을 골라 범위 안으로 가져왔다. PRD를 데스크톱·웹 공통 문서로 고치고 웹 단계를 더한다.

**목표:** 초대 링크를 받은 사람이 로그인 없이 브라우저에서 바로 AI와 공부한다. 공부하다 화면을 캡쳐해 보드에 붙이면 AI가 필기를 만들어 준다.

**결과물**
- 웹 앱(experii.vercel.app): 왼쪽 공부 페이지 목록, 가운데 필기 보드, 오른쪽 AI 대화. 생김새는 데스크톱 앱과 같다
- 캡쳐 → 필기 제안 → [보드에 넣기]. 지금은 연습용 가짜 AI로 돌고, 아침에 키만 넣으면 진짜 Claude로 바뀐다
- 데스크톱·웹 공통 PRD, 웹 기술 설계서, 깃허브 변경 요청(PR), 결과 보고서

**방법**
1. 문서: PRD를 앱 공통으로 고치고 웹 설계서를 쓴다. AI, 30분
2. 뼈대와 저장소: 웹 앱 골격, 서버 DB(Supabase)의 표와 이미지 보관함, 배포 자리. AI, 1시간
3. 캡쳐→필기와 화면: 가짜 AI와 진짜 AI 연결부, 데스크톱의 보드·대화 화면 옮기기. AI, 3시간
4. 검증과 배포: 자동 시험, 실제 브라우저 확인, 운영 배포와 PR. AI, 1시간
5. 진짜 AI 연결: 키를 넣고 실제 캡쳐로 확인. 창업자, 아침 20~30분

**범위**
- 하는 것: 초대 링크 입장, 첫 안내 문구("지금까지 공부 어떻게 했어요? 여기서는 대화 후 캡쳐 → 붙여넣기만 하세요. 필기는 자동으로 해 드려요"), 공부 페이지, AI 대화, 캡쳐 붙여넣기·끌어 놓기·올리기 버튼, 필기 제안 넣기, 실패 시 다시 시도, 하루 사용 한도, 서버 저장
- 시간이 남으면: 대화 답을 끌어다 필기하기
- 하지 않는 것: 로드맵, 경험 카드, 과목, 모델 고르기, ChatGPT 로그인, 계정·동기화, 휴대폰 최적화(깨지지 않는 정도만), 진짜 AI 호출, 데스크톱·랜딩 코드 수정

**정해 줄 것** (추천안으로 진행 중)
1. 필기를 보드에 넣는 방식: **AI 제안을 보고 [넣기]를 누른다(추천)** / 바로 놓는다. 엉뚱한 필기와 낭비를 막는다
2. 비용 가드: **초대 링크 + 한 사람 하루 캡쳐 30회·대화 100회 + 전체 하루 캡쳐 300회(추천)** / 한도 없음
3. 대화 답 끌어다 필기: **시간이 남으면 이번에, 아니면 다음 단계(추천)** / 반드시 이번에
4. 통합 PRD(PR #21, 병합 전)와의 순서: **이 PR을 먼저 병합하고 #21을 웹 결정에 맞춰 고친다(추천)** / #21 먼저. #21의 "GPT만", "필기는 서버에 저장 안 함", "랜딩 PRD 통합"이 이번 결정과 부딪힌다

**비용:** 사람 약 50분(아침 키 연결 20~30분, PR 검토 20분). AI 약 5시간, 09:00 전에 끝낸다. 돈은 0원(Vercel·Supabase 무료 플랜). Claude 사용료는 진짜 연결 뒤 쓴 만큼 나가고 하루 한도가 상한이다

**성공 기준**
- 배포 주소에서 캡쳐를 붙이면 60초 안에 필기 제안이 1개 이상 나오고, 넣은 필기는 새로고침해도 남는다
- Vercel 미리보기 배포와 자동 시험이 통과한다. 코드와 PR 어디에도 키가 없다
- 아침에 키 하나와 설정 두 개만 넣으면 진짜 Claude로 바뀐다

**위험**
1. 진짜 AI 연결부는 밤새 실제로 불러 보지 못한다. 가짜 시험으로 형식을 맞춰 두고 아침 확인 순서를 보고서에 적는다
2. 공개 링크라 비용·개인정보(캡쳐 속 정보) 위험이 있다. 초대 링크, 하루 한도, 업로드 때 "서버에 저장되고 AI로 보내요" 안내로 막는다. 진짜 연결 전에는 링크를 퍼뜨리지 않는다
3. PR #21과 같은 문서를 고친다. 병합 때 사람이 정리해야 하므로 정리 방법을 보고서에 적는다
