교정 1

MCP 서버는 세션을 '읽으러' 가지 않는다

MCP 서버는 Claude가 필요할 때 부르는 함수 묶음입니다. Claude가 대화를 요약해 도구 인자로 넘기면(push) 서버가 저장하고 학습 ID를 돌려줍니다. 세션 원문을 통째로 가져오려면(pull) MCP가 아니라 Claude Code가 남기는 transcript 파일과 hooks를 써야 합니다.

알림 시각은 사람이 아니라 망각이 정해야 한다

08

Python FastMCP로 save_learning 도구 하나짜리 MCP 서버를 만들어, Claude Code에서 "저장해줘" 한마디로 학습 ID가 발급되는 데까지 확인한다.

60분루프 2 · 저장

서버·DB·웹 없이 '대화 → 도구 호출 → 파일에 한 줄 → 학습 ID'만 되는 가장 작은 Experii입니다. 이게 돌아가면 나머지는 살을 붙이는 일입니다.

먼저 알고 시작할 것

  • MCP 서버가 내보내는 것은 tools·resources·prompts 세 종류다. 오늘은 tools만 쓴다.
  • 내 PC에서는 stdio로 연결한다(Claude Code가 서버 프로세스를 직접 띄운다). claude.ai 웹에서 쓰려면 05의 Linear처럼 원격 HTTP + OAuth가 필요하다.
  • stdio 서버 안에서 print()로 stdout에 쓰면 통신이 깨진다. 로그는 stderr로 보낸다.
  • 함수의 docstring이 곧 도구 설명이고, Claude는 이걸 읽고 언제 부를지 정한다.

  2. server.py 뼈대 보기 
    import json
from datetime import datetime, timezone
from pathlib import Path

from mcp.server.fastmcp import FastMCP

mcp = FastMCP("experii")
DB = Path(__file__).parent / "learnings.jsonl"


@mcp.tool()
def save_learning(concept: str, my_explanation: str, confusion: str,
                  practice_task: str, confidence: int) -> str:
    """SQLD 학습 세션에서 정리한 개념 1개를 Experii에 저장하고 학습 ID를 돌려준다.
    저장 전에 저장할 내용을 사용자에게 보여주고 확인받는다. confidence는 1(모름)~4(완벽)."""
    count = sum(1 for _ in DB.open(encoding="utf-8")) if DB.exists() else 0
    record = {
        "learning_id": f"EXP-{count + 1}",
        "saved_at": datetime.now(timezone.utc).isoformat(),
        "concept": concept,
        "my_explanation": my_explanation,
        "confusion": confusion,
        "practice_task": practice_task,
        "confidence": confidence,
    }
    with DB.open("a", encoding="utf-8") as f:
        f.write(json.dumps(record, ensure_ascii=False) + "\n")
    return record["learning_id"]


if __name__ == "__main__":
    mcp.run()
