# Experii 앱 PRD (데스크톱·웹 공통)

2026-10-29 창업자 결정으로 데스크톱 앱 PRD로 작성. 2026-10-30 개정: 핵심 루프에 필기 페이지를 넣고(루프 v2), 모델 선택, 앱 맥락과 앱 안 도구, 답 표시, 사이드바 접기, 카드 만드는 속도를 더했다(FR-10~17). 기술 설계와 단계별 계획은 [데스크톱 TSD](../desktop/tsd.md)를 따르고, 2026-10-30 개정분의 설계와 실행 계획은 [2026-10-30 밤 계획](../plans/2026-10-30-overnight-desktop/ai.md)에 있다.

2026-11-13 개정: 데스크톱·웹 두 앱이 함께 쓰는 PRD로 바꾸고, 파일을 `docs/desktop/prd.md`에서 이 자리로 옮겼다. 10장 "웹 공개 실험 v0"을 더했다. 근거는 창업자 요청 원문 [founder-request.md](../plans/2026-11-13-web-capture-notes/founder-request.md)다.

창업자 결정(2026-11-13): 데스크톱 앱과 웹 앱은 PRD가 같고 TSD(기술 설계서)는 앱마다 따로 둔다. 랜딩은 보이는 화면이 달라서 별도 PRD와 TSD를 쓴다.

## 이 문서의 범위

| 장 | 적용 대상 | 기술 설계 |
|---|---|---|
| 1~9장 | 데스크톱 MVP v1 (`apps/desktop/`) | [docs/desktop/tsd.md](../desktop/tsd.md) |
| 10장 | 웹 공개 실험 v0 (`apps/web/`) | [docs/web/tsd.md](../web/tsd.md) |

1~9장은 데스크톱 MVP v1의 요구사항이다. 2026-11-13 개정에서 내용은 바꾸지 않았고, 웹과 다른 곳(6장, 8장)에 10장을 가리키는 표시만 붙였다.

## 1. 목적과 지표

- **목적:** 공부하는 순간 경험이 쌓이고, 쌓인 경험이 면접에 쓸 만하다는 것을 창업자가 2주 동안 직접 써 보며 확인한다.
- **H2:** 평가한 경험 카드 중 60% 이상이 "면접에 쓸 만해요"다. 카드 지시문 버전(`prompt_version`)별로 잰다.
- **측정 규칙:** H2에 못 미치면 카드 지시문과 형식만 고치고 `prompt_version`을 올려 다시 잰다.

## 2. 사용자

- **v1:** 창업자 본인. Windows PC, ChatGPT Plus 계정.
- **다음:** ChatGPT Plus·Pro 사용자.

## 3. 핵심 루프 (v2, 2026-10-30)

1. **공부:** 오른쪽 GPT 패널에서 과목을 골라 대화하며 공부한다. 대화 세션 하나에서 질문을 여러 번 한다.
2. **필기:** GPT 답에서 남기고 싶은 부분을 드래그해 가운데 필기 페이지에 놓으면 필기가 된다. 대화 세션 하나에 필기 페이지가 하나다.
3. **경험으로 남기기:** 버튼을 한 번 누르면 GPT가 그 대화로 경험 카드를 쓴다. 카드는 필기 페이지의 요약으로 보인다.
4. **로드맵:** 가운데 과목별 세로 경로에 칸(필기 페이지 하나)이 생기고, 그 뒤에 추천 칸 1~2개가 붙는다.
5. **다시 보기·이어 하기:** 칸이나 카드를 누르면 그 필기 페이지가 열리고, 오른쪽에서 그 대화를 이어 간다.
6. **다음 공부 정하기:** 추천 칸 하나를 고르거나 GPT와 상의해서 정한다. 추천을 무엇으로 만들지는 근거 리서치를 보고 정한다. 그전까지는 카드를 만들 때 GPT가 1~2개를 제안한다.

| 위치 | 내용 |
|---|---|
| 왼쪽 사이드바 | 과목 목록과 과목별로 쌓인 경험(카드). 접고 펼 수 있다 |
| 가운데 | 과목별 세로 로드맵과 필기 페이지. 칸이나 카드를 누르면 필기 페이지로 바뀌고, 로드맵으로 돌아올 수 있다 |
| 오른쪽 | GPT 대화 패널. 접고 펼 수 있다 |

## 5. 기능 요구사항

| ID | 요구사항 |
|---|---|
| FR-01 | "Continue with ChatGPT"로 로그인하고 로그아웃한다. Plus·Pro가 아니면 "ChatGPT Plus·Pro 계정이 필요해요"를 띄운다 |
| FR-02 | 과목을 만들고 고른다. 대화는 항상 과목 안에서 시작한다 |
| FR-03 | GPT와 대화한다. 답은 글자 단위로 흘러나온다. 대화 원문은 내 PC에 저장되고, 앱을 다시 켜도 이어서 말할 수 있다 |
| FR-04 | "경험으로 남기기"를 누르면 카드를 만든다. 카드 항목: 제목, 한 줄 요약, 면접 한 마디, STAR, 배운 개념, 다음 할 일 |
| FR-05 | 카드마다 "면접에 쓸 만해요 / 아니에요"를 평가한다 |
| FR-06 | 과목별 로드맵에 지난 칸과 잠긴 추천 칸 1~2개를 보여 준다 |
| FR-07 | 지난 칸이나 카드를 누르면 그 대화의 필기 페이지가 열리고, 오른쪽에서 그 대화를 이어 간다. 잠긴 칸을 누르면 그 주제로 새 대화를 시작한다 |
| FR-08 | 카드에는 대화에 실제로 나온 사실만 쓴다. 학습 내용이 없는 대화는 카드로 만들지 않는다. 키나 개인정보 같은 비밀은 가리고 무엇을 가렸는지 알린다 |
| FR-09 | 입력창 근처에 "Using ChatGPT plan"과 "Manage usage" 링크를 둔다 |
| FR-10 | 입력창 근처에서 쓸 모델을 고른다. 목록은 로그인한 계정이 쓸 수 있는 모델이다. 고른 모델은 그 대화의 다음 메시지부터 쓰고, 새 대화의 기본값이 된다 |
| FR-11 | GPT는 매 요청에서 Experii가 무엇인지, 지금 과목과 모델, 쓸 수 있는 도구와 할 수 없는 일을 안다. 모델 선택처럼 앱이 하는 일을 "못 한다"고 답하지 않는다 |
| FR-12 | GPT가 앱 안 도구를 부를 수 있다. 첫 도구는 "내 경험 카드 검색"이다. 도구를 부르면 대화에 호출 표시가 보인다. 계정이 도구를 받지 않으면 도구 없이 대화한다 |
| FR-13 | GPT 답의 표, 코드 블록, 인라인 코드가 형식대로 보인다. 넓은 표는 가로로 스크롤한다. 답에 든 HTML은 실행하지 않는다 |
| FR-14 | 왼쪽 사이드바와 오른쪽 GPT 패널을 접고 편다(Ctrl+B, Ctrl+Shift+B). 접은 상태는 앱을 다시 켜도 남는다 |
| FR-15 | "경험으로 남기기"를 누르면 카드 자리가 바로 생기고 제목부터 차례로 채워진다. 만드는 동안에도 대화를 계속할 수 있다 |
| FR-16 | GPT 답의 일부를 드래그해 가운데에 놓거나 [필기에 추가]를 누르면 필기가 생긴다. 필기는 원문 그대로 저장되고 어느 질문의 답인지 남는다. 필기를 옮기고 지울 수 있다 |
| FR-17 | 필기 페이지에는 그 대화의 필기들과 경험 카드 요약(제목, 한 줄 요약, 면접 한 마디, 평가)이 보인다. 대화 세션 하나에 필기 페이지가 하나다 |

## 6. v1에서 하지 않는 것

현장 과제, 면접 답변 화면, 리마인더, 모바일, 서버 동기화, 계정, 릴레이 서버, 삭제·내보내기 화면.

2026-10-30에 나중으로 미룬 것: 필기 페이지 하나에 대화 세션 여러 개 붙이기, 외부 플러그인(MCP) 연결(설계만 한다), 다음 공부 추천 엔진(근거 리서치 뒤 정한다), GPT가 필기를 다듬어 주는 기능(데스크톱 v1에 적용, 웹 v0은 10장).

## 7. GPT 연결

| 단계 | 방식 |
|---|---|
| Phase A (v1 도그푸딩) | "Sign in with ChatGPT" 셀프 등록. 내 PC에서 도는 개인 프로젝트로 쓰며, 창업자 PC 밖으로 배포하지 않는다. 상업 파트너 관심 신청서는 지금 제출한다 |
| Phase B (상업 출시 초기) | 창업자 API 키를 쥔 릴레이 서버로 쓰고 비용은 창업자가 낸다. v1에서는 만들지 않는다 |
| Phase C (승인 뒤) | 사용자가 자기 ChatGPT 계정으로 로그인한다 |

공통 제약: OpenAI 서버에 대화를 저장하지 않는다(`store:false`). 그래서 앱이 대화 원문을 내 PC에 두고 매번 다시 보낸다.

## 8. 데이터 경계

- 대화, 필기, 카드, 로드맵은 사용자 PC의 SQLite에만 저장한다. Experii 서버는 없다(데스크톱 v1에 적용, 웹 v0은 10장).
- 대화 내용은 답을 받기 위해 OpenAI로 전송된다. GPT가 앱 안 도구(예: 내 경험 카드 검색)를 부르면 그 결과도 답을 받기 위해 OpenAI로 전송된다.
- 로그인 토큰은 Windows 암호화 저장소(DPAPI)로 암호화해 둔다.

## 10. 웹 공개 실험 v0 (2026-11-13)

`apps/web/`의 웹 앱이다. 기술 설계는 [docs/web/tsd.md](../web/tsd.md)를 따른다. 1~9장과 다른 점은 이 장이 정한다.

### 10.1 목적과 판정

- **목적:** 초대 링크를 받은 사람이 URL로 Experii를 써 보게 한다. 화면 캡쳐를 보드에 올리면 AI가 필기를 만들어 준다.
- **판정:** 캡쳐를 올리면 60초 안에 필기 블록이 생기고, Vercel Preview(미리보기 배포)가 통과한다.
- **배포 주소:** `experii.vercel.app`(창업자 지정).

### 10.2 사용자

- 초대 링크가 있는 누구나 쓴다.
- 로그인하지 않는다. 계정을 만들지 않는다.

### 10.3 핵심 루프

1. **대화:** 오른쪽에서 AI와 대화하며 공부한다.
2. **캡쳐 붙이기:** 남기고 싶은 화면을 캡쳐해 가운데 보드에 붙인다.
3. **필기 제안:** AI가 캡쳐를 읽고 필기를 제안한다.
4. **확인하고 넣기:** 사용자가 제안을 보고 [보드에 넣기]로 고른 필기를 보드에 남긴다.

데스크톱 루프의 경험 카드, 로드맵, 다음 공부 정하기는 웹 v0에 없다.

### 10.4 화면

생김새는 데스크톱 앱과 같은 3단이다(창업자 결정).

| 위치 | 내용 |
|---|---|
| 왼쪽 | 공부 페이지 목록과 새 페이지 |
| 가운데 | 필기 보드. 캡쳐와 필기가 놓인다 |
| 오른쪽 | AI 대화 |

페이지 하나는 대화 하나와 보드 하나다.

### 10.5 기능 요구사항

| ID | 요구사항 |
|---|---|
| FR-W1 | 초대 링크로 들어온다. 코드가 틀리거나 없으면 "초대 링크가 필요해요"를 띄운다 |
| FR-W2 | 처음 들어오면 안내 문구를 띄운다: "지금까지 공부 어떻게 했어요? 여기서는 대화 후 캡쳐 → 붙여넣기만 하세요. 필기는 자동으로 해 드려요." 닫으면 이 브라우저에서는 다시 뜨지 않는다 |
| FR-W3 | 왼쪽에 공부 페이지 목록이 있고 새 페이지를 만든다. 페이지를 고르면 그 페이지의 대화와 보드가 열린다 |
| FR-W4 | AI와 대화한다. 답은 글자 단위로 흘러나온다. 표와 코드는 FR-13과 같이 보인다. 대화는 새로고침한 뒤에도 남는다 |
| FR-W5 | 캡쳐를 보드에 붙인다. 방법은 Ctrl+V, 이미지 파일 끌어 놓기, [캡쳐 올리기] 버튼 세 가지다. png·jpg·webp만 받는다. 브라우저에서 줄여 4MB 이하로 올린다. 붙인 자리에 캡쳐가 바로 보인다 |
| FR-W6 | 캡쳐를 붙이면 60초 안에 필기 제안이 0~8개 생긴다. 규칙은 10.8을 따른다 |
| FR-W7 | 제안마다 [넣기]와 [빼기]가 있고, 한꺼번에 넣는 [모두 넣기]가 있다. 확신이 낮은 제안은 흐리게 보이고 "확인해 보세요"가 붙는다. 넣은 필기는 보드에 남는다 |
| FR-W8 | 필기를 만들지 못하면 캡쳐 원본은 보드에 남기고 실패를 알린다. [다시 시도]는 캡쳐 하나에 최대 3번이다 |
| FR-W9 | 보드는 점 격자 배경이고 이동·확대할 수 있다. 필기와 캡쳐를 옮기고 지운다. 새로고침한 뒤에도 그대로 남는다 |
| FR-W10 | 사용량 한도: 한 사람 하루 캡쳐 30회, 대화 100회. 전체 하루 캡쳐 300회. 넘으면 한도에 닿았다고 안내한다 |
| FR-W11 | 첫 캡쳐를 올릴 때 "캡쳐는 Experii 서버에 저장되고 필기를 만들려고 AI로 보내요"를 알린다. 비밀번호나 개인정보가 보이는 화면은 올리지 말라는 말도 함께 쓴다 |
| FR-W12 | 대화 답의 일부를 끌어 보드에 놓으면 필기가 생긴다(`source = drag-from-chat`). 원문 그대로 저장한다. 이번 스프린트에서는 시간이 남을 때만 한다 |
| FR-W13 | 연습 모드 표시: 실제 AI를 연결하기 전에는 지금 보이는 답과 필기가 예시라는 것을 화면에 밝힌다 |

### 10.6 하지 않는 것

로드맵, 경험 카드, 과목, 모델 고르기, ChatGPT 로그인, 계정·동기화, 휴대폰 최적화(화면이 깨지지 않는 정도만 맞춘다).

실제 AI 호출은 창업자가 연동하기 전까지 하지 않는다. 그때까지는 목(mock, 연습용 가짜 AI)으로 돈다.

### 10.7 AI 연결

- **AI:** Claude API(Anthropic). 데스크톱의 GPT 연결(7장)과 다르다.
- **비용과 키:** 창업자가 낸다. API 키는 서버 환경 변수(env)에만 두고 브라우저로 보내지 않는다.
- **실연동 전:** 목 어댑터로 돈다. 목과 실제 연결은 같은 입출력 형식을 쓴다. 개발 중에는 AI나 에이전트가 실제 Anthropic API를 부르지 않는다.
- **모델:** 서버 env `CLAUDE_MODEL`로 정한다. 사용자는 모델을 고르지 않는다. 기본값과 실연동 절차는 [웹 TSD](../web/tsd.md)에 있다.

### 10.8 필기 생성 규칙

1. **사실만:** 이미지에 보이는 내용만 쓴다. 추측, 보강, 외부 지식을 넣지 않는다.
2. **톤 B:** 학습 필기 톤으로 짧게 다시 쓴다.
3. **언어:** 이미지 언어와 상관없이 `text`는 항상 한국어다.
4. **비밀:** API 키, 비밀번호, 개인정보는 `text`에 넣지 않고 `[redacted]`로 바꾼다. 가린 곳이 있으면 사용자에게 알린다.
5. **관련 없음:** 비었거나 학습과 관련 없는 이미지는 필기 0개와 이유 한 줄을 돌려준다. 가짜 필기를 만들지 않는다.
6. **개수:** 캡쳐 하나에 최대 8개.
7. **넣기:** 바로 보드에 놓지 않고 제안으로 보여 준다. 사용자가 확인하고 넣는다(FR-W7).

필기 블록(NoteBlock) 필드:

| 필드 | 필수 | 설명 |
|---|---|---|
| `text` | O | 보드에 보이는 필기 본문. 한국어 |
| `kind` | O | `concept` \| `step` \| `quote` \| `warning` \| `todo` \| `other` |
| `source_region` | 권장 | 이미지 위 대략 위치: `top` \| `middle` \| `bottom` \| `full`. 모르면 비운다 |
| `confidence` | 권장 | 0~1. 낮으면 화면에서 흐리게 보이고 확인을 권한다 |
| `raw_excerpt` | 선택 | 이미지에서 읽은 원문. `text`와 다를 수 있다 |

필기의 출처(`source`)는 둘이다.

| 값 | 뜻 |
|---|---|
| `capture-vision` | 캡쳐를 AI가 읽고 만든 필기. 톤 B로 다듬는다 |
| `drag-from-chat` | 대화 답을 끌어 만든 필기. 원문 그대로다(FR-16, FR-W12) |

### 10.9 데이터 경계

- **서버 저장:** 공부 페이지, 대화, 캡쳐 이미지, 필기를 Experii 서버(Supabase)에 저장한다. 데스크톱 v1의 "Experii 서버 없음"(8장)과 다르다.
- **전송:** 캡쳐 이미지는 필기를 만들려고 Anthropic으로 보낸다. 대화 내용도 답을 받으려고 Anthropic으로 보낸다. 목으로 도는 동안에는 밖으로 보내지 않는다.
- **방문자 구분:** 계정 대신 브라우저 쿠키에 담은 무작위 ID로 구분한다. DB의 행 단위 보안 정책(RLS: 표의 행마다 누가 읽고 쓸지 DB가 정하는 규칙)으로 서로의 데이터를 볼 수 없다.
- **그래서:** 쿠키를 지우거나 다른 브라우저로 들어오면 새 방문자가 되어 이전 페이지가 보이지 않는다.
