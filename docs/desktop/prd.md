# Experii 데스크톱 앱 PRD (v1)

2026-10-29 창업자 결정으로 작성. 기술 설계와 단계별 계획은 [tsd.md](tsd.md)를 따른다.

## 1. 목적과 지표

- **목적:** 공부하는 순간 경험이 쌓이고, 쌓인 경험이 면접에 쓸 만하다는 것을 창업자가 2주 동안 직접 써 보며 확인한다.
- **H2:** 평가한 경험 카드 중 60% 이상이 "면접에 쓸 만해요"다. 카드 지시문 버전(`prompt_version`)별로 잰다.
- **측정 규칙:** H2에 못 미치면 카드 지시문과 형식만 고치고 `prompt_version`을 올려 다시 잰다.

## 2. 사용자

- **v1:** 창업자 본인. Windows PC, ChatGPT Plus 계정.
- **다음:** ChatGPT Plus·Pro 사용자.

## 3. 핵심 루프

1. **공부:** 오른쪽 GPT 패널에서 과목을 골라 대화하며 공부한다.
2. **경험으로 남기기:** 대화 끝에 버튼을 한 번 누르면 GPT가 대화로 경험 카드를 쓴다.
3. **로드맵:** 가운데 과목별 세로 경로에 칸이 하나 생기고, 그 뒤에 GPT가 추천한 잠긴 칸 1~2개가 붙는다.
4. **이어 하기:** 칸이나 카드를 누르면 그때의 GPT 대화가 다시 열려 이어서 공부한다.

## 4. 화면

| 위치 | 내용 |
|---|---|
| 왼쪽 사이드바 | 과목 목록과 과목별로 쌓인 경험(카드) |
| 가운데 | 듀오링고식 세로 로드맵. 지난 칸에는 무엇을 배웠는지(카드 제목과 한 줄 요약), 뒤에는 잠긴 추천 칸 |
| 오른쪽 | GPT 대화 패널 |

세부 화면은 시안 3개 중 창업자가 고른 안을 따른다(`.claude/rules/ui-change.md`).

## 5. 기능 요구사항

| ID | 요구사항 |
|---|---|
| FR-01 | "Continue with ChatGPT"로 로그인하고 로그아웃한다. Plus·Pro가 아니면 "ChatGPT Plus·Pro 계정이 필요해요"를 띄운다 |
| FR-02 | 과목을 만들고 고른다. 대화는 항상 과목 안에서 시작한다 |
| FR-03 | GPT와 대화한다. 답은 글자 단위로 흘러나온다. 대화 원문은 내 PC에 저장되고, 앱을 다시 켜도 이어서 말할 수 있다 |
| FR-04 | "경험으로 남기기"를 누르면 카드를 만든다. 카드 항목: 제목, 한 줄 요약, 면접 한 마디, STAR, 배운 개념, 다음 할 일 |
| FR-05 | 카드마다 "면접에 쓸 만해요 / 아니에요"를 평가한다 |
| FR-06 | 과목별 로드맵에 지난 칸과 잠긴 추천 칸 1~2개를 보여 준다 |
| FR-07 | 지난 칸이나 카드를 누르면 그 대화를 다시 연다. 잠긴 칸을 누르면 그 주제로 새 대화를 시작한다 |
| FR-08 | 카드에는 대화에 실제로 나온 사실만 쓴다. 학습 내용이 없는 대화는 카드로 만들지 않는다. 키나 개인정보 같은 비밀은 가리고 무엇을 가렸는지 알린다 |
| FR-09 | 입력창 근처에 "Using ChatGPT plan"과 "Manage usage" 링크를 둔다 |

## 6. v1에서 하지 않는 것

현장 과제, 면접 답변 화면, 리마인더, 모바일, 서버 동기화, 계정, 릴레이 서버, 삭제·내보내기 화면, 모델 선택.

## 7. GPT 연결

| 단계 | 방식 |
|---|---|
| Phase A (v1 도그푸딩) | "Sign in with ChatGPT" 셀프 등록. 내 PC에서 도는 개인 프로젝트로 쓰며, 창업자 PC 밖으로 배포하지 않는다. 상업 파트너 관심 신청서는 지금 제출한다 |
| Phase B (상업 출시 초기) | 창업자 API 키를 쥔 릴레이 서버로 쓰고 비용은 창업자가 낸다. v1에서는 만들지 않는다 |
| Phase C (승인 뒤) | 사용자가 자기 ChatGPT 계정으로 로그인한다 |

공통 제약: OpenAI 서버에 대화를 저장하지 않는다(`store:false`). 그래서 앱이 대화 원문을 내 PC에 두고 매번 다시 보낸다.

## 8. 데이터 경계

- 대화, 카드, 로드맵은 사용자 PC의 SQLite에만 저장한다. Experii 서버는 없다.
- 대화 내용은 답을 받기 위해 OpenAI로 전송된다.
- 로그인 토큰은 Windows 암호화 저장소(DPAPI)로 암호화해 둔다.
